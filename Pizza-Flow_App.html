Identificar al cliente

Busca por teléfono. Si no existe, escribe sus datos; se guardarán cuando acepte el pedido.

El sistema buscará el número en la base de datos. Si es un cliente nuevo, no lo guardará hasta que acepte el pedido.

Tomar y calcular el pedido

Los productos, precios y zonas se cargan desde la API.

Elegir un método no significa que el pago ya se haya recibido. El pago quedará pendiente.

Enviar y confirmar la comanda

La API registra la comunicación; no envía mensajes ni realiza llamadas externas.
